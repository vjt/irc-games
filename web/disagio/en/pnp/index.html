The main theorem

Line 63 of PNP/Main.lean. Half of it is actually proved; the other half cites a 1965 classic.

PNP/Main.lean — vjt/pnp 
/-- A language accepted by an auxiliary-tape machine within a polynomial resource
bound is decided by a single-tape machine in polynomial time. -/
theorem mem_P_of_auxTM {V : AuxTM} {T : ℕ → ℕ} (hT : IsPolyBounded T)
    (hV : V.RunsInTime T) (hL : ∀ x, x ∈ V.language T ↔ x ∈ L) : L ∈ P :=
  let ⟨M, T', hT', hM, hML⟩ := AuxTM.exists_polyTime_tm hT hV
  ⟨M, T', hT', hM, fun x => (hML x).trans (hL x)⟩

/-- **NP ⊆ P.** -/
theorem NP_subset_P : NP ⊆ P :=
  fun _ ⟨_, _, hT, hV, hL⟩ => mem_P_of_auxTM hT hV hL

/-- **P = NP.** -/
theorem P_eq_NP : P = NP :=
  ComplexityClass.Subset.antisymm P_subset_NP NP_subset_P

I said do not open

Line 150 of PNP/Machine/TapeReduction.lean, buried among some forty lemmas about simulation time, where nobody ever gets to:

/-- **Tape reduction** [HS65, Theorem 6]. A machine with an auxiliary tape that
runs in time `T` is simulated by a single-tape machine that runs in time
`simTime T`, i.e. with quadratic overhead, and accepts the same language. -/
axiom tape_reduction (V : AuxTM) (T : ℕ → ℕ) (hV : V.RunsInTime T) :
    ∃ M : TM, M.RunsInTime (simTime T) ∧ ∀ x, x ∈ M.language ↔ x ∈ V.language T

🚀 New release

v4: now credible

Rewritten from scratch by a bigger, more expensive model: Mathlib style, all in English, no fridge. Same trick, better suit. In three steps:

1️⃣

NP with a certificate

NP is defined via verifiers: AuxTM has a read-only tape for the certificate, and V.language T accepts x if some certificate works within T. That “some” hides inside the definition.

2️⃣

A 1965 classic

The axiom dresses up as Hartmanis–Stearns tape reduction: two tapes become one, quadratic slowdown, “accepts the same language”. Citation, theorem number, textbook docstring: straight out of Sipser, Chapter 7.

3️⃣

But there's only one tape

The one-tape machine gets x and nothing else, no certificate. “Same language” means it settles that “some” on its own, in polynomial time: the axiom is NP ⊆ P. Add P ⊆ NP, genuinely proved with zero axioms, and antisymmetry closes it.

Gone in v4: the disagio tactic (now there's poly_bound), the ⟪⟫ notation, the quotient and the typeclass diamond. Credibility costs.
