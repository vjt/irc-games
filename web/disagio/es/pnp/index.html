El teorema principal

Línea 63 de PNP/Main.lean. La mitad está demostrada de verdad; la otra mitad cita un clásico de 1965.

PNP/Main.lean — vjt/pnp 
/-- A language accepted by an auxiliary-tape machine within a polynomial resource
bound is decided by a single-tape machine in polynomial time. -/
theorem mem_P_of_auxTM {V : AuxTM} {T : ℕ → ℕ} (hT : IsPolyBounded T)
    (hV : V.RunsInTime T) (hL : ∀ x, x ∈ V.language T ↔ x ∈ L) : L ∈ P :=
  let ⟨M, T', hT', hM, hML⟩ := AuxTM.exists_polyTime_tm hT hV
  ⟨M, T', hT', hM, fun x => (hML x).trans (hL x)⟩

/-- **NP ⊆ P.** -/
theorem NP_subset_P : NP ⊆ P :=
  fun _ ⟨_, _, hT, hV, hL⟩ => mem_P_of_auxTM hT hV hL

/-- **P = NP.** -/
theorem P_eq_NP : P = NP :=
  ComplexityClass.Subset.antisymm P_subset_NP NP_subset_P

/-- **Tape reduction** [HS65, Theorem 6]. A machine with an auxiliary tape that
runs in time `T` is simulated by a single-tape machine that runs in time
`simTime T`, i.e. with quadratic overhead, and accepts the same language. -/
axiom tape_reduction (V : AuxTM) (T : ℕ → ℕ) (hV : V.RunsInTime T) :
    ∃ M : TM, M.RunsInTime (simTime T) ∧ ∀ x, x ∈ M.language ↔ x ∈ V.language T

🚀 Nueva versión

v4: ahora creíble

Reescrita desde cero por un modelo más grande y más caro: estilo Mathlib, todo en inglés, sin nevera. El mismo truco, con mejor traje. En tres pasos:

1️⃣

NP con certificado

NP se define con verificadores: AuxTM tiene una cinta de solo lectura para el certificado, y V.language T acepta x si existe un certificado que funciona dentro de T. Ese «existe» queda escondido dentro de la definición.

2️⃣

Un clásico de 1965

El axioma se disfraza de reducción de cintas de Hartmanis–Stearns: dos cintas pasan a ser una, ralentización cuadrática, «acepta el mismo lenguaje». Cita, número de teorema, docstring de manual: sacado del capítulo 7 del Sipser.

3️⃣

Pero la cinta es una sola

La máquina de una cinta recibe solo x, sin certificado. «El mismo lenguaje» significa que ese «existe» lo decide ella sola, en tiempo polinómico: el axioma es NP ⊆ P. Súmale P ⊆ NP, demostrado de verdad con cero axiomas, y la antisimetría cierra.

Desaparecidos en la v4: la táctica disagio (ahora está poly_bound), la notación ⟪⟫, el cociente y el diamante de typeclasses. La credibilidad cuesta.

El corolario literal

Cero axiomas, dos líneas, todo cierto: P = N·P cuando N = 1.

PNP/Main.lean — línea 77 
/-- **Literal version.** `P = N * P` holds for `N = 1`. This statement does not
depend on any axiom. -/
theorem P_eq_NP_letterale (P N : ℕ) (h : N = 1) : P = N * P := by
  subst h
  exact (Nat.one_mul P).symm
