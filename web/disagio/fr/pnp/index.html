Le théorème principal

Ligne 63 de PNP/Main.lean. Une moitié est vraiment démontrée, l’autre moitié cite un classique de 1965.

PNP/Main.lean — vjt/pnp 
/-- A language accepted by an auxiliary-tape machine within a polynomial resource
bound is decided by a single-tape machine in polynomial time. -/
theorem mem_P_of_auxTM {V : AuxTM} {T : ℕ → ℕ} (hT : IsPolyBounded T)
    (hV : V.RunsInTime T) (hL : ∀ x, x ∈ V.language T ↔ x ∈ L) : L ∈ P :=
  let ⟨M, T', hT', hM, hML⟩ := AuxTM.exists_polyTime_tm hT hV
  ⟨M, T', hT', hM, fun x => (hML x).trans (hL x)⟩

/-- **NP ⊆ P.** -/
theorem NP_subset_P : NP ⊆ P :=
  fun _ ⟨_, _, hT, hV, hL⟩ => mem_P_of_auxTM hT hV hL

/-- **P = NP.** -/
theorem P_eq_NP : P = NP :=
  ComplexityClass.Subset.antisymm P_subset_NP NP_subset_P

Non. N’ouvre pas.

J’ai dit : n’ouvre pas

Ligne 150 de PNP/Machine/TapeReduction.lean, noyée parmi une quarantaine de lemmes sur le temps de simulation, là où personne n’arrive :

/-- **Tape reduction** [HS65, Theorem 6]. A machine with an auxiliary tape that
runs in time `T` is simulated by a single-tape machine that runs in time
`simTime T`, i.e. with quadratic overhead, and accepts the same language. -/
axiom tape_reduction (V : AuxTM) (T : ℕ → ℕ) (hV : V.RunsInTime T) :
    ∃ M : TM, M.RunsInTime (simTime T) ∧ ∀ x, x ∈ M.language ↔ x ∈ V.language T

Le kernel ne ment pas : #print axioms Complexity.P_eq_NP passe aux aveux, et un #guard_msgs tout en bas de PNP/Main.lean fige la sortie, donc chaque build de la CI revérifie :

'Complexity.P_eq_NP' depends on axioms: [propext, Quot.sound, Complexity.AuxTM.tape_reduction]
'Complexity.P_eq_NP_letterale' does not depend on any axioms
'Complexity.P_subset_NP' does not depend on any axioms

Une démonstration honnête : il suffit de la lire en entier, ce que justement personne ne fait.

🚀 Nouvelle version

v4 : désormais crédible

Réécrite de zéro par un modèle plus gros et plus cher : style Mathlib, tout en anglais, plus de frigo. Même truc, plus beau costume. En trois étapes :

1️⃣

NP avec certificat

NP se définit par vérificateurs : AuxTM a un ruban en lecture seule pour le certificat, et V.language T accepte x s’il existe un certificat qui marche en temps T. Ce « il existe » se cache dans la définition.

2️⃣

Un classique de 1965

L’axiome se déguise en réduction de rubans de Hartmanis–Stearns : deux rubans deviennent un, ralentissement quadratique, « accepte le même langage ». Citation, numéro de théorème, docstring de manuel : tout droit sorti du chapitre 7 du Sipser.

3️⃣

Mais il n’y a qu’un ruban

La machine à un ruban ne reçoit que x, pas de certificat. « Même langage » veut dire qu’elle tranche ce « il existe » toute seule, en temps polynomial : l’axiome est NP ⊆ P. Ajoute P ⊆ NP, vraiment démontré avec zéro axiome, et l’antisymétrie conclut.

Disparus dans la v4 : la tactique disagio (place à poly_bound), la notation ⟪⟫, le quotient et le diamant de typeclasses. La crédibilité, ça coûte.

Le corollaire littéral

Zéro axiome, deux lignes, tout est vrai : P = N·P quand N = 1.

PNP/Main.lean — ligne 77 
/-- **Literal version.** `P = N * P` holds for `N = 1`. This statement does not
depend on any axiom. -/
theorem P_eq_NP_letterale (P N : ℕ) (h : N = 1) : P = N * P := by
  subst h
  exact (Nat.one_mul P).symm
