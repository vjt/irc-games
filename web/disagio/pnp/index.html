Il teorema principale

Riga 63 di PNP/Main.lean. Metà è dimostrata davvero, l'altra metà cita un classico del 1965.

PNP/Main.lean — vjt/pnp 
/-- A language accepted by an auxiliary-tape machine within a polynomial resource
bound is decided by a single-tape machine in polynomial time. -/
theorem mem_P_of_auxTM {V : AuxTM} {T : ℕ → ℕ} (hT : IsPolyBounded T)
    (hV : V.RunsInTime T) (hL : ∀ x, x ∈ V.language T ↔ x ∈ L) : L ∈ P :=
  let ⟨M, T', hT', hM, hML⟩ := AuxTM.exists_polyTime_tm hT hV
  ⟨M, T', hT', hM, fun x => (hML x).trans (hL x)⟩

/-- **NP ⊆ P.** -/
theorem NP_subset_P : NP ⊆ P :=
  fun _ ⟨_, _, hT, hV, hL⟩ => mem_P_of_auxTM hT hV hL

/-- **P = NP.** -/
theorem P_eq_NP : P = NP :=
  ComplexityClass.Subset.antisymm P_subset_NP NP_subset_P

/-- **Tape reduction** [HS65, Theorem 6]. A machine with an auxiliary tape that
runs in time `T` is simulated by a single-tape machine that runs in time
`simTime T`, i.e. with quadratic overhead, and accepts the same language. -/
axiom tape_reduction (V : AuxTM) (T : ℕ → ℕ) (hV : V.RunsInTime T) :
    ∃ M : TM, M.RunsInTime (simTime T) ∧ ∀ x, x ∈ M.language ↔ x ∈ V.language T

🚀 Nuova release

v4: ora credibile

Riscritta da capo da un modello più grosso e più costoso: stile Mathlib, tutto in inglese, niente frigo. Il trucco è lo stesso, solo vestito meglio. In tre passi:

1️⃣

NP col certificato

NP si definisce coi verificatori: AuxTM ha un nastro di sola lettura per il certificato, e V.language T accetta x se esiste un certificato che funziona entro T. Quell'«esiste» sta nascosto dentro la definizione.

2️⃣

Un classico del 1965

L'assioma si traveste da riduzione dei nastri di Hartmanis–Stearns: due nastri diventano uno, rallentamento quadratico, «accetta lo stesso linguaggio». Citazione, numero del teorema, docstring da manuale: roba da capitolo 7 del Sipser.

3️⃣

Ma il nastro è uno solo

La macchina a un nastro riceve solo x, il certificato no. «Stesso linguaggio» vuol dire che quell'«esiste» se lo decide da sola, in tempo polinomiale: l'assioma è NP ⊆ P. Poi P ⊆ NP, dimostrato davvero con zero assiomi, e l'antisimmetria chiude.

Spariti nella v4: la tattica disagio (ora c'è poly_bound), la notazione ⟪⟫, il quoziente e il diamante di typeclass. La credibilità costa.

Il corollario letterale

Zero assiomi, due righe, tutto vero: P = N·P quando N = 1.

/-- **Literal version.** `P = N * P` holds for `N = 1`. This statement does not
depend on any axiom. -/
theorem P_eq_NP_letterale (P N : ℕ) (h : N = 1) : P = N * P := by
  subst h
  exact (Nat.one_mul P).symm
