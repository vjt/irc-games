O teorema principal

Linha 63 do PNP/Main.lean. Metade é demonstrada de verdade; a outra metade cita um clássico de 1965.

PNP/Main.lean — vjt/pnp 
/-- A language accepted by an auxiliary-tape machine within a polynomial resource
bound is decided by a single-tape machine in polynomial time. -/
theorem mem_P_of_auxTM {V : AuxTM} {T : ℕ → ℕ} (hT : IsPolyBounded T)
    (hV : V.RunsInTime T) (hL : ∀ x, x ∈ V.language T ↔ x ∈ L) : L ∈ P :=
  let ⟨M, T', hT', hM, hML⟩ := AuxTM.exists_polyTime_tm hT hV
  ⟨M, T', hT', hM, fun x => (hML x).trans (hL x)⟩

/-- **NP ⊆ P.** -/
theorem NP_subset_P : NP ⊆ P :=
  fun _ ⟨_, _, hT, hV, hL⟩ => mem_P_of_auxTM hT hV hL

/-- **P = NP.** -/
theorem P_eq_NP : P = NP :=
  ComplexityClass.Subset.antisymm P_subset_NP NP_subset_P

🚀 Versão nova

v4: agora crível

Reescrita do zero por um modelo maior e mais caro: estilo Mathlib, tudo em inglês, sem geladeira. A mesma pegadinha, de terno novo. Em três passos:

1️⃣

NP com certificado

NP é definido por verificadores: AuxTM tem uma fita só de leitura pro certificado, e V.language T aceita x se existe um certificado que funciona dentro de T. Esse “existe” fica escondido dentro da definição.

2️⃣

Um clássico de 1965

O axioma se fantasia de redução de fitas de Hartmanis–Stearns: duas fitas viram uma, desaceleração quadrática, “aceita a mesma linguagem”. Citação, número do teorema, docstring de livro-texto: direto do capítulo 7 do Sipser.

3️⃣

Só que a fita é uma só

A máquina de uma fita recebe só o x, sem certificado. “Mesma linguagem” quer dizer que ela decide esse “existe” sozinha, em tempo polinomial: o axioma é NP ⊆ P. Junta com P ⊆ NP, demonstrado de verdade com zero axiomas, e a antissimetria fecha.

Sumiram na v4: a tática disagio (agora tem poly_bound), a notação ⟪⟫, o quociente e o diamante de typeclasses. Credibilidade custa caro.

O corolário literal

Zero axiomas, duas linhas, tudo verdade: P = N·P quando N = 1.
