Главная теорема

Строка 63 в PNP/Main.lean. Половина доказана по-настоящему, вторая половина ссылается на классику 1965 года.

PNP/Main.lean — vjt/pnp 
/-- A language accepted by an auxiliary-tape machine within a polynomial resource
bound is decided by a single-tape machine in polynomial time. -/
theorem mem_P_of_auxTM {V : AuxTM} {T : ℕ → ℕ} (hT : IsPolyBounded T)
    (hV : V.RunsInTime T) (hL : ∀ x, x ∈ V.language T ↔ x ∈ L) : L ∈ P :=
  let ⟨M, T', hT', hM, hML⟩ := AuxTM.exists_polyTime_tm hT hV
  ⟨M, T', hT', hM, fun x => (hML x).trans (hL x)⟩

/-- **NP ⊆ P.** -/
theorem NP_subset_P : NP ⊆ P :=
  fun _ ⟨_, _, hT, hV, hL⟩ => mem_P_of_auxTM hT hV hL

/-- **P = NP.** -/
theorem P_eq_NP : P = NP :=
  ComplexityClass.Subset.antisymm P_subset_NP NP_subset_P

/-- **Tape reduction** [HS65, Theorem 6]. A machine with an auxiliary tape that
runs in time `T` is simulated by a single-tape machine that runs in time
`simTime T`, i.e. with quadratic overhead, and accepts the same language. -/
axiom tape_reduction (V : AuxTM) (T : ℕ → ℕ) (hV : V.RunsInTime T) :
    ∃ M : TM, M.RunsInTime (simTime T) ∧ ∀ x, x ∈ M.language ↔ x ∈ V.language T

Ядро не врёт: #print axioms Complexity.P_eq_NP во всём признаётся, а #guard_msgs в конце PNP/Main.lean намертво фиксирует вывод, так что каждый билд CI проверяет признание заново:

🚀 Новый релиз

v4: теперь правдоподобно

Переписано с нуля моделью побольше и подороже: стиль Mathlib, всё на английском, без холодильника. Подвох тот же, костюм получше. В три шага:

1️⃣

NP с сертификатом

NP определяется через верификаторы: у AuxTM есть лента только для чтения под сертификат, а V.language T принимает x, если существует сертификат, который срабатывает за T. Это «существует» спрятано внутри определения.

2️⃣

Классика 1965 года

Аксиома переодета в редукцию лент Хартманиса–Стирнса: две ленты превращаются в одну, квадратичное замедление, «распознаёт тот же язык». Ссылка, номер теоремы, docstring как из учебника: прямо из седьмой главы Сипсера.

3️⃣

Но лента-то одна

Одноленточная машина получает только x, без сертификата. «Тот же язык» значит, что это «существует» она решает сама, за полиномиальное время: аксиома и есть NP ⊆ P. Добавляем P ⊆ NP, честно доказанное без единой аксиомы, и антисимметрия всё закрывает.

В v4 пропали: тактика disagio (теперь есть poly_bound), нотация ⟪⟫, фактортип и ромб тайпклассов. Правдоподобие стоит дорого.

Буквальное следствие

Ноль аксиом, две строки, всё честно: P = N·P при N = 1.

PNP/Main.lean — строка 77 
/-- **Literal version.** `P = N * P` holds for `N = 1`. This statement does not
depend on any axiom. -/
theorem P_eq_NP_letterale (P N : ℕ) (h : N = 1) : P = N * P := by
  subst h
  exact (Nat.one_mul P).symm
