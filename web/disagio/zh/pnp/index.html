核心定理

PNP/Main.lean 第 63 行。一半是真证出来的，另一半引用了一篇 1965 年的经典。

PNP/Main.lean — vjt/pnp 
/-- A language accepted by an auxiliary-tape machine within a polynomial resource
bound is decided by a single-tape machine in polynomial time. -/
theorem mem_P_of_auxTM {V : AuxTM} {T : ℕ → ℕ} (hT : IsPolyBounded T)
    (hV : V.RunsInTime T) (hL : ∀ x, x ∈ V.language T ↔ x ∈ L) : L ∈ P :=
  let ⟨M, T', hT', hM, hML⟩ := AuxTM.exists_polyTime_tm hT hV
  ⟨M, T', hT', hM, fun x => (hML x).trans (hL x)⟩

/-- **NP ⊆ P.** -/
theorem NP_subset_P : NP ⊆ P :=
  fun _ ⟨_, _, hT, hV, hL⟩ => mem_P_of_auxTM hT hV hL

/-- **P = NP.** -/
theorem P_eq_NP : P = NP :=
  ComplexityClass.Subset.antisymm P_subset_NP NP_subset_P

说了别点开

PNP/Machine/TapeReduction.lean 第 150 行，夹在四十来个关于模拟时间的引理中间，一个没人会读到的地方：

/-- **Tape reduction** [HS65, Theorem 6]. A machine with an auxiliary tape that
runs in time `T` is simulated by a single-tape machine that runs in time
`simTime T`, i.e. with quadratic overhead, and accepts the same language. -/
axiom tape_reduction (V : AuxTM) (T : ℕ → ℕ) (hV : V.RunsInTime T) :
    ∃ M : TM, M.RunsInTime (simTime T) ∧ ∀ x, x ∈ M.language ↔ x ∈ V.language T

内核不会撒谎：#print axioms Complexity.P_eq_NP 会如实招供。PNP/Main.lean 末尾还有一个 #guard_msgs 把输出钉死，所以每次 CI 构建都会重新核对一遍：

'Complexity.P_eq_NP' depends on axioms: [propext, Quot.sound, Complexity.AuxTM.tape_reduction]
'Complexity.P_eq_NP_letterale' does not depend on any axioms
'Complexity.P_subset_NP' does not depend on any axioms

一份诚实的证明：只要从头读到尾就行——而这恰恰是没人会做的事。

🚀 全新版本

v4：现在可信了

由一个更大、更贵的模型从头重写：Mathlib 风格，全英文，冰箱下岗。猫腻还是那个猫腻，只是西装更体面了。分三步：

1️⃣

带证书的 NP

NP 用验证器来定义：AuxTM 有一条只读纸带专门放证书，V.language T 接受 x，只要存在一个在 T 步内管用的证书。这个“存在”就藏在定义里。

2️⃣

1965 年的经典

公理打扮成 Hartmanis–Stearns 的纸带归约：两条纸带变一条，平方级减速，“接受同一个语言”。有引用、有定理编号、有教科书式文档注释：仿佛直接摘自 Sipser 第 7 章。

3️⃣

可纸带只有一条

单带机只拿到 x，拿不到证书。“同一个语言”意味着那个“存在”得由它自己在多项式时间内判定：这条公理就是 NP ⊆ P。再加上零公理、货真价实证出来的 P ⊆ NP，反对称性一收尾，完事。

v4 里消失的：disagio 策略（现在是 poly_bound）、⟪⟫ 记号、商类型和类型类菱形。可信是要花钱的。

字面意义上的推论

零公理，两行，句句属实：当 N = 1 时，P = N·P。

PNP/Main.lean — 第 77 行 
/-- **Literal version.** `P = N * P` holds for `N = 1`. This statement does not
depend on any axiom. -/
theorem P_eq_NP_letterale (P N : ℕ) (h : N = 1) : P = N * P := by
  subst h
  exact (Nat.one_mul P).symm
